# 審核通知與中途之家介面改善

2026-09-08，使用者已核准。工作分支 `feature/260908-review-notifications`；沿用 dev 基底的 C1/C2 相依提交，尚未合併 dev，不自動推送或 merge。

## 契約

- 核准／退回寄有效 Owner/Admin；停權／恢復寄全體有效成員。事件時選定收件人，讀取與寄送時重查資格，停權不取消狀態通知。
- 同一交易更新組織、audit、每位收件人的站內通知及 outbox。無歷史補寄。email 與協尋偏好無關。
- 沿用 PostgreSQL outbox，不引入外部 queue。通知採事件＋版本＋收件人唯一鍵；SMTP 重試仍可能重複投遞，不承諾 exactly-once。
- 每次 SMTP 接受只記為 SENT（郵件服務已接受），不宣稱到達收件匣。失敗分類、延遲重試、租約復原、人工重送與 heartbeat 必須可驗收。
- 保留暖色樣式；只調整中途卡片及通知區，不全面重設、不全站取消文字連結底線。

## 實作與驗收

依 `tasks/todo.md` 順序完成。API 採既有 session、same-origin、no-store；通知查詢限本人且目前仍有資格。停止 workers 不會遺失 DB 中的工作。

- 外部信件無法保證收件匣／已讀；站內通知為可查詢的可靠後援。
- C1/C2 尚在工作分支，不能將本機完成說成 dev 已發布。
