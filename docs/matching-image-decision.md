# 圖片配對 go / no-go

## 本輪決策：No-go

目前沒有至少 30 個具授權、已知相關候選的 human-reviewed 圖片事件，因此不能合理估計圖片召回或排序增益。現在先保留規則配對與可解釋訊號，不新增 pgvector、embedding API 或圖片資料庫欄位。

圖片方案的限制：

| 方案 | 能改善 | 不能改善 |
|---|---|---|
| 只重排現有候選 | 外觀相似候選排序 | 規則召回已漏掉的動物 |
| 圖片召回與規則召回 union | 部分特徵標示缺漏 | 無照片、低品質照片、模型誤判 |
| 先改善資料與規則 | 來源錯誤、缺值、同義詞 | 複雜外觀辨識 |

重新開啟圖片實驗的 gate：至少 30 個有授權圖片的 human-reviewed 事件、按事件凍結 holdout、無照片 fallback 可驗證；holdout Hit@10 至少比規則 baseline 高 5 個百分點、candidate recall 不下降、無照片結果完全一致，且本機 ranker p95 不超過 baseline 兩倍。未達成時維持 no-go，不修改標註來追求數字。
