# [M-13] 台灣城市列表中「嘉義」重複，且未區分嘉義市和嘉義縣

| 欄位 | 內容 |
|------|------|
| **嚴重等級** | 🟠 Medium |
| **狀態** | Open |
| **分類** | bug |
| **影響功能** | 城市驗證（cityInTaiwan 函數） |

## 問題描述

`taiwanCities.utils.ts` 中「嘉義」出現兩次，且台灣行政區劃中有「嘉義市」和「嘉義縣」兩個不同的行政單位，農業部 API 資料中可能使用不同的稱呼，需要分別支援。

## 影響的檔案與位置

- `backend/src/libs/taiwanCities.utils.ts` 第 14-15 行

## 根本原因（Root Cause）

```typescript
const taiwanCities = [
    // ...
    '嘉義',
    '嘉義',  // ← 重複
    '屏東',
    // ...
];
```

## 影響範圍（Impact）

若後續使用城市列表生成 UI 下拉選單，會出現重複的「嘉義」選項。同時，農業部 API 中地址可能使用「嘉義市」或「嘉義縣」，若 `cityInTaiwan` 只有「嘉義」，可能無法正確匹配完整的行政區名稱。

## 修復規格（Fix Specification）

### 需要的修改

**`taiwanCities.utils.ts`**
```typescript
// Before（有重複）:
const taiwanCities = [
    // ... 其他城市
    '嘉義',
    '嘉義',  // 重複
    '屏東',
];

// After（補全並去重）:
const taiwanCities = [
    '台北市', '新北市', '桃園市', '台中市', '台南市', '高雄市',
    '基隆市', '新竹市', '嘉義市',
    '新竹縣', '苗栗縣', '彰化縣', '南投縣', '雲林縣',
    '嘉義縣', '屏東縣', '宜蘭縣', '花蓮縣', '台東縣',
    '澎湖縣', '金門縣', '連江縣',
    // 保留舊稱以相容舊資料
    '台北', '新北', '桃園', '台中', '台南', '高雄', '嘉義', '屏東',
];
```

### 修改後的預期行為

城市列表無重複，「嘉義市」和「嘉義縣」都能被 `cityInTaiwan` 正確匹配。

## 驗收條件（Acceptance Criteria）

- [ ] `cityInTaiwan('嘉義市')` 回傳 `true`
- [ ] `cityInTaiwan('嘉義縣')` 回傳 `true`
- [ ] 城市列表中無重複項目
