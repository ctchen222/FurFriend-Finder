## 本批範圍

- `/organizations`：我的中途之家，支援清單分頁、空狀態及錯誤重試。
- `/organizations/new`：個人／團隊建立表單；保留不需要住家地址的隱私提示；相同內容重試沿用 requestId。
- `/orgs/:id`：成員工作空間，顯示名稱、角色、一個主要狀態與已填寫的介紹資料；停權／關閉優先於審核及公開狀態。
- 登入後主導覽有「我的中途之家」；個人空間與組織清單可互相返回。
- Email 與 Google 登入只接受明確白名單內的組織返回路徑，不開放任意外部 redirect。
- 工作空間依 user ID + organization ID 重新掛載，切換時不顯示前一組織資料；重新聚焦及重新整理頁面會重新檢查權限。
- 目前尚未提供邀請、審核、發布及動物刊登按鈕，不能把這批前端視為 C1 全部完成。

## 收容所瀏覽設計

現有排序保留：update_date DESC → open_date DESC → id DESC。依使用者回饋，畫面不再顯示排序與定位說明，亦不宣稱最近拾獲、距離最近或推薦順位。

```text
收容所動物
  物種              縣市／地址（可輸入、有縣市建議）
  收容所選單        性別
  [查詢] [重置]
  已套用條件 → 動物結果 → 分頁
```

- 收容所地址不是動物拾獲地點。現有資料沒有結構化座標，本批不請求定位、不推算距離。
- 新增公開 `GET /api/animals/shelters`，只回政府收容所名稱、地址、電話與 ID；不混入中途組織私人資料。
- 清單最多 500 間，超過會明確提示截斷；當前真實資料共 33 間。
- 新增 `shelterId` query，SQL 在排序與分頁前作精確 ID 過濾；名稱相同也不會混為同一所。
- 地區輸入變動立即清除表單內的收容所選擇；按查詢才套用結果，並清除分頁游標。
- 網址保留地區、收容所、物種、性別及游標，可分享與重新整理。
- 選項不存在／不屬於目前地區時保留該 ID 並說明，不偷偷換成全部收容所；使用者可清除或重置。
- 收容所清單載入失敗不阻擋既有其他篩選；可獨立重載清單。
- 無符合動物時沿用空狀態；前往之前提示聯絡收容所確認。

真正的附近距離排序另需：可信任的收容所座標、定位同意與拒絕／逾時回退、未知座標處理、距離排序游標，以及不得把定位存入個人資料的預設。已向使用者提出範圍確認，未將地區搜尋當成距離搜尋。

## 驗收方式

- Jest：精確 shelterId 條件、清單查詢界限、組織 HTML 直接路由。
- Playwright：建立重試、組織切換撤權、Google callback、安全狀態、320／768／1024／1440 寬度；收容所切換、分享、失敗與重置。
- 真實 API：確認 33 間收容所、選取單一收容所回傳資料的 shelter_id 全數一致、無效 ID 拒絕。
- `auth.spec.ts` 增加真實註冊 → Mailpit 驗證 → 建立組織 → 重新整理 → 回個人空間；會建立專用驗收帳號與未公開的「React 驗收中途之家」，不修改既有帳號。
- 公開中途名錄、邀請／移轉、認養流程、pg_trgm 仍在後續 C 批次，未在本批宣稱完成。
